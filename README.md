# わんにゃんごはんカルテ

取得ドメイン: `wannyan-gohan.com`

## 初期サービス

シニア犬フード診断。7歳以上の犬を対象に、年齢・体型・悩み・健康診断の気になる項目から、以下を整理するMVPです。

- 1日の必要カロリー
- おやつ上限
- 食事の優先順位
- 健診結果に応じた相談推奨メモ
- 候補フード
- 詳細ごはんカルテPDFの需要確認導線

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

本サイトはペットフード選びの参考情報を提供するもので、診断・治療・療法食の指示ではありません。持病、症状、療法食利用中の場合は獣医師に相談してください。
