TYPE GUIDE

飼い主と走る子タイプ

社交性：外の刺激は少し距離を取って確認したい慎重さ：新しいことを試す力がある活動性：遊び・散歩・反応の熱量が高め飼い主との距離感：飼い主とのつながりが安心材料

外では少し警戒するけれど、活発で好奇心もある。何より飼い主が一番のタイプ。慣れた自宅で新フードを試すと成功しやすく、運動量が多いのでおやつの量には注意。

特徴（この子にありそうなこと）

  • 知らない人や犬には少し距離を置いて確認する
  • 新しい物事に対する好奇心はあり、安心できれば積極的に挑戦する
  • 遊びや散歩への意欲が高く、エネルギッシュに動き回る
  • 飼い主への愛着が強く、そばにいることで安心して力を発揮する
  • 外では警戒しても、家の中では活発に過ごす

接し方のコツ

  • 外での警戒は無理に克服させず、飼い主が安心の基地になる
  • 慣れた自宅や信頼できる場所で新しい挑戦をさせると成功しやすい
  • 運動意欲が高い分、発散の機会を十分に確保する
  • 飼い主と離れる時間は少しずつ慣らしていく

フードの見直し方

慣れた自宅で新フードを試すと成功しやすいタイプです。飼い主がそばにいる安心できる環境で切り替えを始めると、警戒心が和らぎやすい傾向があります。

  • 切り替えは自宅の慣れた場所・時間帯で行う
  • 運動量が多いため、活動量に見合ったカロリー量を確保する
  • おやつの量が多くなりやすいので、主食量から差し引いて調整する

注意したい健診項目

持病の診断ではなく、うちの子タイプの傾向から「相談時に聞いてみるとよい項目」を整理したものです。数値の解釈や治療方針は主治医にご確認ください。

  • 体重（活動量が多い一方、警戒によるカロリー消費の変動もある）
  • 分離不安に伴う食欲・行動の変化
  • 外出先でのストレス性の消化器の様子

向きやすい商品カテゴリ

特定の商品をおすすめするものではなく、このタイプの傾向と相性が良さそうなカテゴリの目安です。

  • 慣れた環境で与えやすい、いつもと変わらない食感のフードが向きやすい傾向があります
  • 活動量に見合ったカロリー設計のフードが合いやすい傾向があります
  • 家庭で管理しやすい計量済みパッケージも選択肢になりやすい傾向があります
