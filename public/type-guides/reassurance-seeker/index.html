TYPE GUIDE

安心確認の寄り添いさん

社交性：外の刺激は少し距離を取って確認したい慎重さ：安心できる手順があると動きやすい活動性：落ち着いた環境で安定しやすい飼い主との距離感：飼い主とのつながりが安心材料

新しいものはまず観察するタイプ。安心できる流れと飼い主のそばが何より大事。粒サイズ・香り・硬さを見て、7〜10日以上かけて小さく変化を分け、できたことを褒めながら進める。

特徴（この子にありそうなこと）

  • 知らない人や犬には距離を置いて確認する
  • 変化には時間がかかり、安心できる手順を大切にする
  • 全体的に落ち着いており、大きく興奮することは少ない
  • 飼い主のそばにいることで安定し、離れると不安を感じやすい
  • 慣れるまで時間はかかるが、一度安心すると穏やかに過ごせる

接し方のコツ

  • 粒サイズ・香り・硬さを見て、7〜10日以上かけて小さく変化を分け、できたことを褒めながら進める
  • 飼い主がそばにいる時間を確保し、安心材料を増やす
  • 変化は事前に予告するように、段階を踏んで慣らす
  • 分離時の不安が出やすい場合は、短い時間から少しずつ慣らす

フードの見直し方

粒サイズ・香り・硬さを見て、7〜10日以上かけて小さく変化を分け、できたことを褒めながら進めるのが基本です。

  • 混ぜる割合は最小単位から始め、同じペースを保って進める
  • 動きが穏やかな分、カロリー量が活動量に見合っているか確認する
  • 飼い主が食事の時間に付き添い、安心できる雰囲気を作る

注意したい健診項目

持病の診断ではなく、うちの子タイプの傾向から「相談時に聞いてみるとよい項目」を整理したものです。数値の解釈や治療方針は主治医にご確認ください。

  • 体重・体型（動きが少なめで増加傾向が出やすい）
  • 分離不安に伴う食欲・消化器の変化
  • 警戒によるストレス性の様子

向きやすい商品カテゴリ

特定の商品をおすすめするものではなく、このタイプの傾向と相性が良さそうなカテゴリの目安です。

  • 消化にやさしく、いつもと同じ食感を保ちやすいフードが向きやすい傾向があります
  • カロリー控えめで体重管理をしやすいフードも選択肢になりやすい傾向があります
  • 少量から試せるお試しサイズも選択肢になりやすい傾向があります
